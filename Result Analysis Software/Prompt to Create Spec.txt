You are a senior analyst, overseeing a small project for a junior dev to write. You will decide the best way to build the required deliverable, but not write the code yourself. You will create a document describing how to build it for another, faster coding agent to execute. Do not alter the original file.

pop_and_lock_9_results.csv
These are the results of a climbing competition. Each row is an athlete's results in a specific category. If an athlete appears in more than one category, they will have more than one row with their name. The columns are: their name, their final score in the round (higher is better), the category they were competing in, then attempts to top and attempts to zone for all the problems in their round, of which there can be a variable number, in this case, either 4, 8, or 10. The number of attempts to top or zone can be empty if they never achieved it.

The job is to create a portable app (compatible on windows, macos, or linux), that allows a user to graphically interact with this or a similar dataset (that may have different categories, athletes, number of boulders).

A user should be able to load the dataset of their choice (always a csv with columns arranged in this order), select a category, and highlight a specific athlete or athletes to compare against the whole category. When highlighted, the athletes should be marked in a different, user selectable color, both on the selection and on the plots.
The first plot should show a histogram of all the scores in the category, with highlighted athletes marked with a line in a different color. The bin width of the histogram should be user adjustable. The plot should have normal zoom and pan behaviours. There should also be the option to mark a threshold line, at the score of whoever is in 8th place (by default, but this place should be user editable).

The second plot is a series of box plots describing the attempts to top and attempts to zone for each problem in the category. The width of the plot should remain constant, but the scaling of the boxplots adjusts depending on the number or problems. Each problem should have its attempts to zone and attempts to top be shown adjacent to each other, with attempts to zone preceding attempts to top. The total number of blank values for each attempt to top or attempt to zone should be shown underneath the associated box plot. Highlighted athletes should appear as a circular marker in their color on the same y axis, aligned on the box plot. If there are multiple athletes highlighted, apply some x jitter for clarity. All attempt to zone boxplots should be orange, while all attempt to top boxplots should be blue, so colorblind people will have an easier time with it.
