Competitive climbing is a relatively new sport, and small in the scale of economy and revenue. As a result, the tools and infrastructure surrounding data collection and management is lacking, especially as you go to smaller competitive regions. In Canada, the results of competitions are usually found on the CEC Live Results page. This page does not stay up long, is difficult to extract data from, and only really useful to see where you placed. 

As a former researcher, I wanted to use my (very minimal) data analysis skills to build a small toolset to help coaches and athletes better understand the results of their performance, and thus be able to track performance in a more grounded way. I still believe climbing is a very personal, individualized sport, and that over-commodifying it will not be to its benefit, some metrics can be useful when used wisely.

The toolset will hopefully be composed of the following items, all made as simple Python Apps that are portable between Windows, Mac, and Linux.
- A tool that extracts the data from the website into a more operable csv format
- A tool that takes the compiled data and offers different visualizations so that programs can see how they compare to the whole demographic.

I would also like to incorporate the ability to tag and mark boulder problems with style or movement keywords, such that we can highlight weaknesses and strengths more clearly, and potentially allow setters to more objectively know their audience as well.

I am using local AI to write the code itself, and so I will be including all the prompts and test data for transparency.
